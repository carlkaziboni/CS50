# 🎓 Harvard CS50 Portfolio

This repository contains my solutions to problem sets and projects from Harvard's CS50: Introduction to Computer Science course. The collection demonstrates my journey through various programming concepts, languages, and paradigms.

## 📚 Course Overview

CS50 is Harvard University's introduction to computer science and programming, covering concepts from algorithms and data structures to software engineering and web development. This course explores languages including C, Python, SQL, JavaScript, CSS, and HTML.

### Week 10: Final Project

#### Description
The final project is a **Suggestion System** designed for a student council or similar organization. It allows users (students, parents, teachers, or anyone else) to submit suggestions to the student council. The suggestions are reviewed by council members or staff, who can approve, reject, or mark them as "in progress." The system also allows users to track the status of their suggestions.

#### Features
- **User Roles**: Regular users can submit suggestions, while admins can approve/reject suggestions and manage the system.
- **Suggestion Tracking**: Users can track the status of their suggestions (approved, rejected, or in progress).
- **Admin Panel**: Admin users can review and update suggestion statuses, as well as manage user accounts and meeting minutes.
- **Database**: Uses an SQLite database to store users, suggestions, meeting minutes, and statuses.

#### Technologies Used
- **Flask** for web development.
- **Bootstrap** for frontend styling.
- **Flask-Login** for user authentication.
- **SQLite** for database management.
- **HTML, CSS** for frontend design.
